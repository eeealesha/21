# Референсы дашбордов для воркшопа Дня 2

Для Блока 1 воркшопа («UI/UX дашбордов») координатору нужно распечатать **4 примера** дашбордов: **1 удачный** и **3 проблемных**. Ниже — конкретные источники.

Сейчас они приведены как ссылки на публичные дашборды и сценарий «что показать», чтобы не зависеть от того, какой именно отчёт МЗ РФ доступен на момент проведения интенсива.

---

## Удачный пример (1 шт.)

### Reference A — Госуслуги, дашборд «Запись к врачу»

- **Источник:** скриншот публичного интерфейса записи к врачу на портале Госуслуг (`gosuslugi.ru` → «Здоровье» → «Запись к врачу»).
- **Почему удачный:**
  - Одна цель: выбрать слот.
  - Минимум визуального шума: 3 цвета максимум (синий/серый/зелёный).
  - Кнопки целевого действия крупнее остального.
  - Время до записи (главный KPI пациента) — наверху, видно за 1 секунду.
- **Что подсветить группе:** «Дашборд — это не таблица. Дашборд — это интерфейс к действию. Госуслуги — пример, как государство умеет делать UX, когда задача чётко поставлена».

**Альтернатива, если Госуслуги недоступны:** дашборд DataLens «Население городов России» в открытой галерее Yandex (`datalens.yandex.cloud/marketplace`) — у него та же структура: одна цель, три цвета, KPI наверху.

## Проблемные примеры (3 шт.)

### Reference B — Открытые данные Минздрава РФ (ЕМИАС / mosgorzdrav)

- **Источник:** скриншот любого публичного отчёта со страницы открытых данных Минздрава РФ (`https://minzdrav.gov.ru/open_data`) или регионального МЗ (Москва: `https://mosgorzdrav.ru/ru-RU/info/static/statisticheskaya-otchetnost.html`).
- **Что найти:** таблицу-отчёт с десятками показателей в одной сводной таблице, без выделения главного.
- **Что подсветить группе:** «Это не дашборд, это отчёт в Excel. Какое действие он провоцирует? Никакое. Главврач его прочитает и забудет».

### Reference C — Дашборд Росстата

- **Источник:** интерактивный график на сайте Росстата (`https://rosstat.gov.ru/folder/13721`) — раздел «Здравоохранение», подраздел «Заболеваемость».
- **Что найти:** график с радугой цветов (≥5–7 цветов в легенде), 3D-эффектами или пай-чартом с >10 секторами.
- **Что подсветить группе:** «Цвет должен помогать, а не путать. Здесь цвет несёт декоративную нагрузку — это шум».

### Reference D — Любой проблемный COVID-дашборд периода 2020–2021

- **Источник:** скриншот стопкоронавирус.рф периода пика (`https://стопкоронавирус.рф`), архивная версия из Wayback Machine, если живой убран. Альтернатива: статья «13 худших COVID-дашбордов мира» — поищите по этому запросу, статей много.
- **Что найти:** «всё на одной странице»: карта + 8 графиков + бегущая строка + новости. Пользователь не понимает, куда смотреть.
- **Что подсветить группе:** «Один дашборд — одна цель. Если на дашборде 15 виджетов о разном — он не работает ни для одной аудитории. Все вокруг них ходят».

## Если интернета нет / распечатать не успели

Минимально достаточно нарисовать на флипчарте **2 контрастных схематичных макета:**

```
✓ УДАЧНО                        ✗ ПЛОХО
+---------------------------+   +---------------------------+
|  KPI 1   KPI 2   KPI 3    |   |  пай-чарт с 12 секторами  |
+---------------------------+   |  + легенда на пол-экрана  |
|                  |        |   |                           |
|   Главный        | фильтры|   |    маленький график  таблица    |
|   график         |        |   |    в 3D с тенями     с 50 строк |
|                  |        |   |                           |
+---------------------------+   +---------------------------+
| Топ-5 МО к действию       |   |  ещё 3 виджета внизу       |
+---------------------------+   +---------------------------+
```

Этого достаточно для обсуждения главных правил.
