# Общий датасет интенсива

Единый источник данных на все три дня.

## Запуск

```
python3 create_datasets.py
```

Скрипт создаёт три файла рядом с собой:

- `dataset_v1.csv` — для Дня 1
- `dataset_v2.csv` — для Дня 2
- `dataset_v3.csv` — для Дня 3

Все данные воспроизводимы (`random.seed(42)`): у всех групп — одинаковые числа.

## Структура

См. [`data_dictionary.md`](data_dictionary.md) — описание полей и эволюция датасета.

## Важно

- Эти файлы **не нужно коммитить** в репозиторий группы. Они генерируются на месте.
- В каждом проекте предполагается, что генератор запущен в начале дня. Если файла нет — запусти скрипт.
- Никаких параллельных версий: только то, что создал этот скрипт.
