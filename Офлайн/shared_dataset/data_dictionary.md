# Словарь данных интенсива

Один и тот же набор медицинских организаций — 24 МО (по 12 в Регионе А и Регионе Б) — проходит сквозь все три дня. Что меняется — глубина данных.

---

## `dataset_v1.csv` — День 1

Годовые агрегированные показатели по 24 МО. **Сырой файл с ошибками ввода** — для упражнения по нормализации.

| Поле | Тип | Описание |
|------|-----|----------|
| `mo_id` | строка | Уникальный идентификатор МО (например, `МО-А01`, `МО-Б07`) |
| `mo_name` | строка | Название МО (тип + район) |
| `region` | строка | `Регион А` / `Регион Б` (встречаются в разных регистрах) |
| `district` | строка | Район обслуживания |
| `population` | число | Численность прикреплённого населения. **Есть пропуски** |
| `elderly_share` | число | Доля населения 65+, от 0 до 1 |
| `admitted_total` | число | Поступило за год |
| `discharged` | число | Выписано с улучшением |
| `transferred` | число | Переведено в другую МО |
| `deaths` | число | Летальных исходов в стационаре |
| `letality_pct` | смешанное | Больничная летальность, %. Часть значений — с запятой как десятичным разделителем |

**8 классов намеренных дефектов в v1** (для упражнения «Аудит выгрузки» в Дне 1, Задание 5):

1. **Плавающий регистр `region`** — встречаются `Регион А`, `регион а`, `Регион Б`, `регион б`
2. **Пропуски в `population`** — хотя бы 1 пустая ячейка
3. **Смешанный формат `letality_pct`** — часть значений с запятой (`4,01`), часть с точкой (`4.01`)
4. **Полный дубликат строки** — 1 строка дублируется целиком
5. **Опечатка в `mo_name`** — например, `Раонная больница` вместо `Районная больница`
6. **`population` как строка с приближением** — например, `≈85000` вместо числа
7. **Отрицательный `transferred`** — `-3` в одной строке (явная ошибка ввода)
8. **Десятичная ошибка в `letality_pct`** — в одной строке значение в ~10 раз выше истинного (например, `66.38` вместо `6.64`). Обнаруживается сверкой `deaths / admitted_total * 100`.

## `dataset_v2.csv` — День 2

Помесячная динамика за 2023–2024 годы (24 месяца × 24 МО = 576 уникальных строк; в файле 577 из-за намеренного дубликата — дефект №2). Чистые данные, расширенные кадрами и оборудованием.

| Поле | Тип | Описание |
|------|-----|----------|
| `mo_id`, `region`, `district` | — | См. v1 |
| `year` | число | 2023 или 2024 |
| `month` | строка | Месяц по-русски (`январь`, `февраль`, …) |
| `month_idx` | число | 1–12 |
| `population`, `elderly_share` | — | См. v1 |
| `admitted` | число | Поступило за месяц |
| `discharged`, `transferred`, `deaths` | число | См. v1, помесячно |
| `letality_pct` | число | Помесячная больничная летальность, % |
| `vacancy_reanim_pct` | число | Вакансий реаниматологов, % от штатного расписания |
| `vacancy_cardio_pct` | число | Вакансий кардиологов, % |
| `vacancy_surgeon_pct` | число | Вакансий хирургов, % |
| `ivl_units` | число | Аппаратов ИВЛ в МО, шт. |
| `ct_units` | число | Компьютерных томографов, шт. |
| `angiograph_units` | число | Ангиографов, шт. |
| `ivl_avg_age_years` | число | Средний возраст парка ИВЛ, лет |
| `time_to_ivl_min` | число | Среднее время от поступления до начала ИВЛ, минут |

**Подсказка для гипотез Дня 2:** `vacancy_reanim_pct` и `time_to_ivl_min` коррелируют с летальностью сильнее, чем суммарное число коек.

**8 классов намеренных дефектов в v2** (для упражнения «Аудит выгрузки от МИАЦ» в Дне 2, Задание 1):

1. **«Восстановленные» `time_to_ivl_min` в 3 МО Региона Б за апрель–май 2024** — маркер: значения с 3 знаками после запятой (`53.123` вместо обычных `53.1`). Соответствует комментарию в письме МИАЦ. **Содержательная аномалия, не технический брак.**
2. **Дубликат строки** — `МО-А05`, март 2024 присутствует дважды
3. **Отрицательная `vacancy_reanim_pct`** — `-1.0` в одной строке (явная ошибка ввода)
4. **Аномально низкое `time_to_ivl_min = 4`** в 2 строках — либо ошибка единиц (секунды/минуты), либо ошибка фиксации
5. **Подозрительные `letality_pct = 0`** в 5 строках при `admitted > 0` — статистически возможно при малых выборках, но требует ручной проверки
6. **`ivl_units = 0`** в 2 МО при ненулевом `time_to_ivl_min` — несогласованность полей (как ИВЛ запускалась без аппарата?)
7. **Опечатки в названиях месяцев** — `сентябь`, `янврь`, `нобярь` в 3 строках
8. **Тип-микс в `population`** — одна строка с значением `н/д` вместо числа

## Что изменилось между v1 и v2

МИАЦ в ответ на ТЗ Дня 1 доставил очищенные и расширенные данные:

| Поле в v1 | Что стало в v2 | Почему |
|-----------|----------------|--------|
| `mo_name` | удалено | избыточно — выводится из `mo_id` через справочник МО |
| `admitted_total` | `admitted` | переименовано: теперь это помесячный показатель, не годовой |
| Дефекты v1 (1)–(8) | устранены | МИАЦ выполнил требования к качеству из ТЗ |
| — | + новые поля (см. таблицу v2) | МИАЦ добавил кадры, оборудование, время до манипуляции |
| — | + новые типы дефектов | Появились **содержательные аномалии** и тонкие технические дефекты — задача Дня 2 их найти |

**Принцип:** v2 ⊃ v1 по управленческим показателям, но не по столбцам. Это реалистично — реальные системы редко переименовывают поля без причины, а МИАЦ здесь это сделал, поскольку ТЗ запросило более детальный срез.

## `dataset_v3.csv` — День 3

`dataset_v2.csv` + 2022 год (исторический ряд) + плановые целевые показатели + привязка к Федпроекту. 36 месяцев × 24 МО = 864 строки.

| Поле | Тип | Описание |
|------|-----|----------|
| *Все поля из v2*, **кроме** `letality_pct` | — | См. v2 |
| `letality_pct_fact` | число | Фактическая помесячная летальность, % |
| `letality_pct_plan` | число | Плановый показатель на месяц, %. Для 2022 — пусто (план не ставился) |
| `federal_project` | строка | `Развитие здравоохранения` |

**Подсказка для Дня 3:** разрыв `fact − plan` в Регионе Б за 2024 — главный аргумент в обосновании перед Минздравом РФ.

---

## Принципы

- **Воспроизводимость:** `random.seed(42)`. У всех групп — одинаковые числа.
- **Эволюция, не параллель:** все поля `v1` есть в `v2` (с уточнением до месяца), все поля `v2` есть в `v3`. Дублирующие колонки не появляются.
- **Имитация реальности:** значения подобраны так, чтобы:
  - Регион Б показывал значимо более высокую летальность
  - Главный драйвер — нехватка реаниматологов и время до ИВЛ, а не «возраст оборудования вообще»
  - Сезонность видна (январь, февраль, июль, декабрь чуть хуже)
