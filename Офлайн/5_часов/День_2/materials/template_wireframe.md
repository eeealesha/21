## Анти-дашборд (как НЕ надо)

```
+--------------------------------------------------------------------------------------+
| Дашборд "Аналитика здравоохранения региона"                                          |
+--------------------------------------------------------------------------------------+
|  [3D пай-чарт]      |  [3D пай-чарт]    |   [Радар на 8 осей]  |  [Барчарт]          |
|  Структура поток    |  Возраст пациентов|   Качество           |  Бюджет             |
|  по специальностям  |  по 10 группам    |   по 8 направлениям  |  по статьям         |
|  (с тенями)         |  (легенда сбоку)  |   (нечитаемо)        |  (12 столбцов)      |
+--------------------------------------------------------------------------------------+
|  [Карта]            |  [Линейный график]|   [Воронка]          |  [Облако тегов]     |
|  Россия по регионам |  6 линий          |   Конверсия          |  ?                  |
|  (зачем?)           |  без легенды      |   из приёма в выпис. |                     |
+--------------------------------------------------------------------------------------+
|     [Хедер с логотипом региона на четверть экрана]   [Дата обновления крупно]        |
+--------------------------------------------------------------------------------------+
```

**Что не так с анти-дашбордом:**
- Нет одной цели. Это «всё про здравоохранение», то есть ничего.
- Нет ни одного KPI на верхней строке.
- 3D-эффекты и тени — визуальный шум.
- Карта России без выделения региона — украшение, а не инструмент.
- Облако тегов — нечитаемо в принципе.
- Логотип занимает место главного графика.
- За 5 секунд не понятно, что нужно сделать. За 30 секунд — тоже.

## Что обязательно зафиксировать в `task3_dashboard_spec.md`

Для каждого из 4–6 виджетов:

```
### KPI 1: Летальность месяца

- **Что меряет:** усреднённая больничная летальность по выбранным МО за
  текущий месяц.
- **Источник:** `dataset_v2.csv`, поле `letality_pct`, агрегат AVG по фильтру.
- **Цветовой код:** зелёный <план; жёлтый ≤ план + 1 п.п.; красный > план + 1 п.п.
- **Какое действие провоцирует:** если красный — открыть «Список к действию»
  внизу и понять, какие 5 МО формируют превышение.
```
