### Задание 1: Impact Map стратегии — ⏱ 75 мин

**Для выполнения нужно знать:** фреймворк Impact Mapping (Why → Who → How → What), различие между «бизнес-целью» и «проектом», логика клинического пути пациента.

Impact Map — это управленческая карта, которая связывает цель программы с конкретными инициативами через **изменения в поведении** учреждений и людей. Идеален для медицины — он повторяет логику клинического пути.

**Структура:**

- **Why (Цель):** Сократить разрыв в больничной летальности с Регионом А на 30 % к 2027 году
- **Who (Кто меняет поведение):** Главврачи МО, реаниматологи, диспетчеры скорой, фонд ОМС, региональное министерство
- **How (Как меняется поведение):** Что эти люди должны начать делать по-другому
- **What (Что мы для этого делаем):** Конкретные 6–10 инициатив с метриками

**Старт:** шаблон [`materials/template_impact_map.md`](materials/template_impact_map.md).

**Выполни следующие шаги:**

1. На листе А3 или в Miro нарисуйте Impact Map по шаблону.
2. Привяжите ветки к 2–3 подтверждённым гипотезам из `День_2/task2_hypotheses_check.md`. Каждая ветка должна **опираться на данные**, а не на интуицию.
3. Для каждой инициативы укажите: метрику успеха, срок (3/6/12/24 мес), роль-ответственный, оценочную стоимость (low / mid / high).
4. Выделите **3 инициативы максимального приоритета** (highest impact × lowest cost) — их вы и защищаете вечером.
5. Отдельным абзацем — **что вы НЕ делаете и почему**. Программа без явного «нет» — это не программа, это пожелания.

**Результат:** `task1_impact_map.png` (фото/скан/экспорт) + `task1_impact_map.md` (текстовая расшифровка с приоритетами).

### Задание 2: Новые KPI «to-be» — ⏱ 60 мин

**Для выполнения нужно знать:** различие между «выходными показателями» и «процессными»; критерии хорошего KPI (Specific, Measurable, Actionable, Relevant, Time-bound); почему KPI «летальность» сам по себе — плохой управленческий KPI.

Большинство региональных KPI — это **валовые исходные показатели**. Они показывают, что **уже произошло**, и почти ничего не говорят о том, что делать. Сегодня вы заменяете их на **процессные KPI**, которые можно отслеживать в реальном времени.

**Старт:** шаблон [`materials/template_kpi_card.md`](materials/template_kpi_card.md).

**Выполни следующие шаги:**

1. Возьмите 3 главные инициативы из Impact Map (Задание 1).
2. Для каждой инициативы сформулируйте 1–2 процессных KPI по шаблону.
3. Для каждого KPI обоснуйте, **почему он лучше валового аналога**, который сегодня в обороте. Например:
   - **Старый KPI:** «Больничная летальность от ОНМК, %»
   - **Новый KPI:** «Доля случаев ОНМК с временем "поступление → начало тромболизиса" менее 60 минут, %»
   - **Почему лучше:** меряет **поведение врача**, на которое можно влиять, а не **исход**.
4. Для каждого KPI укажите целевое значение и пороги «зелёный / жёлтый / красный».
5. Отдельным разделом — **3 ложных KPI** (анти-KPI), которых нужно избегать. Например, «количество обученных врачей» — это активность, не KPI результата.

**Результат:** `task2_kpi_card.md` в папке группы.

### Задание 4: Привязка к федеральной повестке — ⏱ 60 мин

**Для выполнения нужно знать:** структура Федпроекта «Развитие здравоохранения», логика «Инцидент-Менеджмент» МЗ РФ (выявление → анализ → меры → контроль), правила игры с центром.

Ваша стратегия может быть гениальной, но если она не «состыкована» с федеральной повесткой, центр её не примет. Сегодня вы переводите свою программу на язык, который понимают в Москве.

**Старт:** опорный список показателей — [`materials/federal_project_indicators.md`](materials/federal_project_indicators.md).

**Выполни следующие шаги:**

1. Зафиксируйте 3–5 ключевых целевых показателей Федпроекта по части снижения летальности и обеспеченности кадрами (из опорного списка или через ИИ/открытые источники).
2. Для каждой вашей инициативы из Impact Map (Задание 1) явно укажите, **на какой федеральный показатель она влияет** и через какой механизм.
3. Сформулируйте ваш кейс в логике «Инцидент-Менеджмент»:
   - **Инцидент:** превышение целевого показателя летальности в 3 МО региона
   - **Анализ:** что показали данные (1 абзац)
   - **Меры:** какие 3 инициативы запускаются (привязка к Impact Map)
   - **Контроль:** как мерять прогресс ежемесячно (привязка к новым KPI)
4. Сформулируйте **3 формулировки одной стратегии** — для трёх аудиторий: главврачи региона / Министр здравоохранения РФ / население и СМИ. Должны различаться по тону и содержанию, а не только заменой слов.

**Результат:** `task4_federal_alignment.md` в папке группы.

**Для выполнения нужно знать:** структура защитной презентации (1 главный тезис → 3 опорные точки → 1 главный риск → ask), правила публичной защиты перед федеральным регулятором.

**Старт:** шаблон структуры — [`materials/template_presentation_outline.md`](materials/template_presentation_outline.md).

**Выполни следующие шаги:**

2. Сформулируйте промпт ИИ-спичрайтеру: «Собери презентацию защиты на 5–7 слайдов перед коллегией Минздрава РФ. У нас 20 минут. Аудитория — заместитель министра + 4 директора департаментов.
