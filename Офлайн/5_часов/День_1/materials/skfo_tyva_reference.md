## 4. Шаги стандартизации (Direct Method)

Чтобы получить **возраст-стандартизованный показатель (SMR)** Тывы:

1. Берём **эталонную возрастную структуру** — для России это структура населения РФ (столбец «РФ» в таблице 1).
2. Для каждой возрастной группы считаем «гипотетическое» число случаев в Тыве, если бы там была эталонная возрастная структура: `повозрастная_летальность_Тывы × доля_в_эталоне`.
3. Суммируем по всем возрастным группам.
4. Получаем стандартизованный показатель.

**Расчёт для Тывы:**

```
SMR_Тыва = 2 × 0.186 + 14 × 0.164 + 110 × 0.231 + 620 × 0.198 + 1850 × 0.160 + 5900 × 0.061
        ≈ 0.4  + 2.3  + 25.4 + 122.8 + 296.0 + 359.9
        ≈ 807
```

**Расчёт для СКФО:**

```
SMR_СКФО ≈ 1 × 0.186 + 8 × 0.164 + 65 × 0.231 + 380 × 0.198 + 1240 × 0.160 + 4100 × 0.061
        ≈ 0.2 + 1.3 + 15.0 + 75.2 + 198.4 + 250.1
        ≈ 540
```

**Знак разрыва изменился на противоположный.** После стандартизации Тыва не «лучший» регион округа, а один из проблемных. Если решение о финансировании принималось на сырых данных — деньги пошли бы не туда.

**Урок для вашего кейса (Регион А vs Регион Б):** при сравнении ваших регионов **обязательно** стандартизуйте показатели хотя бы по доле населения 65+ (поле `elderly_share` в `dataset_v1.csv`). Иначе любой отчёт перед губернатором рискует ввести в заблуждение.
