# Управление на основе данных

**Интенсив для топ-менеджмента здравоохранения. Три дня. Один регион. Одно решение.**

Ты — заместитель министра здравоохранения **Региона Б** по цифровому развитию. Президентское поручение: к 2027 году сократить разрыв в больничной летальности с соседним **Регионом А** на 30 %. Данные у тебя есть. Время — три дня. ИИ — твой ассистент. Команда — твой штаб.

Каждый день — **4 основных задания (~5 часов практики) с таймером на каждое + 2 бонусных** (делаются, если осталось время).

## Сквозной кейс

**Регион А** — благополучный субъект РФ: высокая обеспеченность кадрами, современное оборудование, низкая летальность. **Регион Б** — твой регион: летальность по основным нозологиям на 25–40 % выше, обеспеченность реаниматологами на треть ниже, оборудование старше пяти лет в большинстве МО.

В оба региона входят по 12 медицинских организаций (МО) разных категорий. Данные за два года: пациенты, исходы, оснащение, кадры, демография районов.

Поручение из Москвы: за 36 месяцев сократить разрыв на 30 %. Деньги дают. Но сначала — обоснуйте, **куда именно** их потратить, так, чтобы Минздрав РФ принял ваши аргументы.

## Формат работы

- **Группы** по 3–5 человек. Каждая группа — управленческий штаб одного условного региона. Базовое распределение ролей: **министр / главврач / МИАЦ / фонд ОМС**. При 3 участниках двое берут по 2 роли; при 5 — пятый берёт роль «Аналитик-помощник» (работа с CSV, промпты к ИИ, оформление артефактов).
- **Утро** — воркшоп (75–90 мин). Без классических лекций: ведущий разворачивает структуру, группы реагируют и делают микропрактики.
- **День** — проект: **4 основных задания** с таймерами (~5 ч). Кто успел — берёт бонус.
- **Вечер** — взаимная защита (P2P) по чек-листу `check_list.md` каждого дня.

Каждая группа собирает артефакты в общую папку `src/<номер_группы>/День_N/`. На проверку идут только сданные файлы.

## Единый словарь и технические соглашения

- **Регион А** — «эталонный» субъект (12 МО, низкая летальность); **Регион Б** — «проблемный» (12 МО, высокая летальность); **МО** — медицинская организация.
- Ключевые метрики: больничная летальность; стандартизованный показатель (SMR); обеспеченность специалистами; время до манипуляции; вакансии.
- День 1 работает с `dataset_v1.csv`, День 2 — `dataset_v2.csv`, День 3 — `dataset_v3.csv`.
- Генерация (координатор, до начала Дня 1; `random.seed(42)` — у всех групп одинаковые числа): `python3 shared_dataset/create_datasets.py`.
- Участники команду `python3` не запускают — работают с готовыми CSV глазами.
- **Никакого Excel / SQL / Python для участников.** Главный инструмент — ИИ-ассистенты (GigaChat / YandexGPT / ChatGPT) + Miro / FigJam + PowerPoint / Keynote / Google Slides.

Полное описание словаря и датасетов — в [`shared_dataset/data_dictionary.md`](../shared_dataset/data_dictionary.md).

## Как проходить интенсив

1. Прочитать этот файл до начала первого дня.
2. **Координатор** заранее запускает генератор данных и кладёт три CSV в общую папку.
3. Распределить роли в группе.
4. Открыть `День_1/workshop.md` → провести воркшоп → перейти в `День_1/readme.md`.
5. Делать **4 основных задания по таймеру**. Бонус — если осталось время.
6. Вечером — P2P-защита по `День_1/check_list.md`. Затем День 2 → День 3 → финальная защита.
