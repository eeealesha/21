> Пример: «Больничная летальность от ОНМК в Регионе Б за 2024 год — 6,8 %, в Регионе А — 4,5 %. Разрыв — 51 %».

## 2. Промпт к ИИ

> Используй четыре компонента: роль, контекст, ограничения, формат ответа.

```
Роль: ты — методолог Минздрава с 15-летним опытом разбора причин разрыва
показателей между регионами.

Контекст: [твоя корневая проблема одной фразой]. Мы — управленческая команда
региона, нам нужно дерево факторов, чтобы планировать программу снижения.

Ограничения:
- Дерево глубиной 3–4 уровня
- На листьях — только измеримые показатели, которые в принципе можно
  выгрузить из МИС/МИАЦ
- Без общих фраз вроде «качество медицинской помощи» — только конкретика
- Минимум 4 верхних ветки

Формат ответа:
- Markdown-список с отступами
- Для каждого фактора — одно предложение, почему он влияет на корневую проблему
```

**Сырой ответ ИИ (вставь как есть, не редактируй):**

```
[ответ]
```

## 3. Отредактированное дерево (с флагами управляемости)

> Флаги: `[управляем]` — есть рычаги в регионе; `[влияем косвенно]` — нужны
> договорённости с другими ведомствами; `[не управляем]` — внешний фактор,
> только учитываем при анализе.

- Корень: высокая летальность
  - Кадры
    - Вакансии реаниматологов `[управляем]` — почему: ...
    - Стаж работы врачей `[влияем косвенно]` — почему: ...
    - Демография медработников (возраст) `[не управляем]` — почему: ...

    - Демография района `[не управляем]` — почему: ...
