# Ключевые показатели Федпроекта «Развитие здравоохранения» — для воркшопа Дня 3

Раздаточный материал, который координатор интенсива печатает и кладёт каждой группе перед стартом проекта Дня 3. Используется в **Задании 4** проекта («Привязка к федеральной повестке») и в Блоке 3 воркшопа («Государственный контекст»).

Показатели приведены в обобщённой форме (формулировки и плановые значения соответствуют публичным редакциям нацпроекта «Здравоохранение» и его федеральных проектов 2019–2024 / нового нацпроекта «Продолжительность и активная жизнь» 2025–2030). При обновлении нацпроекта актуализируйте файл по официальной редакции на сайте Минздрава РФ (`https://minzdrav.gov.ru`) и портале нацпроектов (`https://национальныепроекты.рф/projects/zdravookhranenie`).

## 5 ключевых показателей для интенсива

| # | Показатель | Целевое значение | Срок | Источник |
|---|------------|------------------|------|----------|
| 1 | Ожидаемая продолжительность жизни при рождении | 78 лет | 2030 | Нацпроект «Здравоохранение» / новый нацпроект «Продолжительность и активная жизнь» |
| 2 | Смертность от болезней системы кровообращения (на 100 тыс. населения) | ≤ 450 | 2024 / снижение к 2030 | Федпроект «Борьба с ССЗ» |
| 3 | Доля населения, охваченного диспансерным наблюдением (% от взрослого населения с хроническими заболеваниями) | ≥ 70 % | 2024 | Федпроект «Развитие первичной медико-санитарной помощи» |
| 4 | Обеспеченность врачами на 10 000 населения (особо — узкими специалистами) | ≥ 40,2 | 2024 | Федпроект «Обеспечение медицинских организаций квалифицированными кадрами» |
| 5 | Доля медицинских организаций, использующих ЕГИСЗ | 100 % | 2024 | Федпроект «Создание единого цифрового контура» |

## Как привязывать инициативы региона к этим показателям

В Задании 4 проекта каждая инициатива из Impact Map должна явно ссылаться на один из показателей. Шаблон формулировки:

> «Инициатива X (например, «программа жилищных сертификатов для реаниматологов») влияет на показатель **#4 (обеспеченность врачами)** через механизм: новые реаниматологи приезжают и остаются → штат закрывается → летальность по реанимационному профилю снижается → косвенно влияет на показатель **#2 (смертность от ССЗ)** — частично, через долю кардиологических ОНМК».

Группа должна показать **прямое и косвенное влияние** для каждой ключевой инициативы.

## Логика «Инцидент-Менеджмент» МЗ РФ — для разговора с центром

Региональная программа упаковывается в 4 шага:

1. **Инцидент:** показатель N (один из 5 выше) ушёл из «зелёной зоны» для нашего региона.
2. **Анализ:** причина по нашим данным (со ссылкой на гипотезы Дня 2).
3. **Меры:** инициативы из Impact Map с KPI, сроками и ответственными.
4. **Контроль:** ежемесячный мониторинг с эскалацией при отклонении (новые процессные KPI из Задания 2).

Если стратегия региона не сформулирована в этой логике — она для центра «не читается».
